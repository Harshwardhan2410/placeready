# PlaceReady – Placement Preparation Portal

A responsive, single-page website to help students prepare for campus placements. Built with HTML, CSS and JavaScript with the help of generative AI.

## Features
- Aptitude quiz with instant feedback and best-score tracking
- Preparation checklist with progress bar (saved in localStorage)
- Resource library with category filters and live search
- Interview tips accordion
- Contact form with validation
- Dark mode toggle and responsive layout

## Run locally
Open `index.html` in any browser. No build step or dependencies.
